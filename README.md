# Alfaaz Lyric Visual Experience

This local website plays the uploaded reference MP4 without altering its original picture, lyrics, timing, or audio.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome or Firefox.
3. Press Play. Use the fullscreen button for a full-screen experience.

The MP4 is included locally. No server, API key, or internet connection is required.
